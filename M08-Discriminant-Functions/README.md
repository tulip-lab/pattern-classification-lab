Learners optimise a linear logistic discriminant, inspect a loss trace, compare
linear and RBF SVMs, and explain regularisation and kernel locality through
cross-validation evidence.

Prerequisites are vectors, dot products, elementary derivatives, binary
classification, and feature scaling. The guided path uses synthetic data and
requires no download.
