# Pattern Classification Lab Repository Guidance

## Scope

This public repository contains student-facing practical materials for Pattern
Classification. Public notebooks, code, data, assets, and practical navigation
are canonical here.

Keep solutions, answer keys, marking material, private teaching notes, drafts,
student data, credentials, private URLs, and restricted datasets out of this
repository. Prefer safe synthetic data, approved public data, or clearly
licensed sources.

## Curriculum identities

Use the `M01`–`M11` module identities defined by the open common core. Assign a
stable session identifier such as `M03A` to each practical and do not reuse it
for a different learning purpose.

Legacy `flip01` links are migration references only. Do not copy a legacy
notebook until its learning alignment, rights, dependencies, secret handling,
online execution, and failure behaviour have been reviewed.

## Student-material requirements

- State the purpose, prerequisites, expected output, and evidence to retain.
- Provide a deterministic or low-dependency baseline where practical.
- Exercise normal, edge or missing-information, and failure behaviour.
- Preserve a clear Google Colab or other online path when external files are
  required, plus correct relative paths for local clones.
- Never hard-code credentials or use unsafe execution examples.
- State permitted collaboration and AI use only when an approved offering has
  supplied those rules.

## Validation

Inspect repository status before editing. Run checks relevant to changed
notebooks or code plus `git diff --check`. When navigation or shared imports
change, perform one complete relevant link or execution check. Do not commit,
merge, push, publish, or change repository visibility without explicit
authorization.
