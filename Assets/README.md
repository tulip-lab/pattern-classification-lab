# Public assets

Store only reviewed assets required by public practical materials. Record the
source and licence of third-party images, diagrams, audio, video, or documents.
Private slides, assessment material, screenshots containing credentials, and
unreviewed generated media do not belong here.

## Shared FLIP identity

`images/flip-banner.png` is the shared TULIP Lab FLIP banner used by the public
course and Lab home pages. It is copied from the TULIP Lab Agentic AI Lab asset
with an identical SHA-256 hash so the Pattern Classification repositories do
not depend on another course repository at render time.
