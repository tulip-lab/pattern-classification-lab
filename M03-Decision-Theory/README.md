## M03A — Bayesian decision and decision boundaries

Learners estimate Gaussian class statistics, calculate posterior probabilities,
visualise decision boundaries, and compare equal-cost and asymmetric-cost
decisions. Evidence includes numeric held-out results and a labelled boundary
figure.

Prerequisites are conditional probability, Bayes' rule, means, covariance, and
basic plotting. The guided path uses synthetic data and requires no download.
