# Data policy

Use data in this order:

1. small synthetic examples created in the practical;
2. reviewed public data stored in this repository;
3. reviewed public data from a stable external source; and
4. restricted or institution-provided data only outside this public repository
   and only with the required authorization.

Every dataset added here must record its source, licence, purpose, fields,
limitations, and any privacy or bias considerations. Do not commit student,
personal, credential, or restricted data.
