# M10 — Deep learning

No aligned public practical has yet been approved. The optimisation and CVXPY
notebooks previously linked from the open-course Deep Learning page do not by
themselves provide a Deep Learning practical and require separate curriculum
review before migration.

A future M10A practical should compare a simple non-neural baseline with a
small neural classifier, retain a training and validation trace, use a held-out
assessment, state seed and compute assumptions, and discuss failure cases. CNN
or sequence extensions should remain optional unless the offering provides the
required time and compute.
